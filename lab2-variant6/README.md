## Задание

Сравнить сортировку пузырьком (с флагом) и сортировку вставками на данных типа **D** (много повторов, [0; 10]).

| Параметр | Значение |
|---|---|
| Размеры n | 500, 1000, 2000, 4000 |
| Тип данных | D — [0; 10] |
| Повторов k | 5 (медиана) |
| Доп. задание | М1 — подсчёт сравнений и обменов/сдвигов |
